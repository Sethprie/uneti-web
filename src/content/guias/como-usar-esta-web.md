La web está organizada en pocas secciones para que siempre sepas dónde buscar.

## Las secciones

| Sección | Qué encuentras |

| [Recursos](/recursos) | Herramientas y enlaces recomendados. |

## Consejos

- El menú de arriba te acompaña en todas las páginas. En el móvil, ábrelo con el botón de las tres rayas.
- Debajo del título de cada página verás dónde estás, por ejemplo *Inicio / Guías / Cómo usar esta web*. Pulsa cualquier parte para volver.
- Con el botón del sol y la luna cambias entre modo claro y oscuro.

> Si algo no se entiende o falta información, avísanos desde [Participa](/participa).
